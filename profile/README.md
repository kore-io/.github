<h1 align="center">Kore</h1>

<p align="center">
  O site de casamento que organiza a lista de convidados sozinha.
</p>

---

O **Kore** é uma plataforma brasileira para o casamento. O casal monta e publica o site do casamento, manda um link para cada grupo de convidados e acompanha as confirmações num painel, sem planilha e sem perguntar para ninguém. O cerimonialista usa o Kore de graça para cuidar de todos os casamentos dos clientes num só lugar.

### O que estamos construindo

- 💍 Site do casamento, com as seções que o casal escolhe
- ✉️ Um link por grupo de convidados, com confirmação de presença por pessoa
- 📊 Painel com o número real de convidados, adultos e crianças
- 🗂️ Área do cerimonialista para acompanhar todos os casamentos dos clientes

### Como trabalhamos

- 🇧🇷 Produto em português, código em inglês.
- 🔒 Segurança e privacidade desde o início: os dados dos convidados pertencem ao casal (LGPD).
- ♿ Interface acessível (WCAG AA).
- 📐 Requisitos bem definidos e documentação consistente antes de cada funcionalidade entrar em desenvolvimento.
- ✅ Todo merge passa por pull request com CI verde.

O produto está em desenvolvimento ativo. Os repositórios entram nesta organização conforme forem criados.
