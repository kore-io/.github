<h1 align="center">Kore</h1>

<p align="center">
  O site de casamento que organiza a lista de convidados sozinha.
</p>

---

O **Kore** é um SaaS brasileiro para o casamento. O casal monta e publica o site do casamento, manda um link para cada grupo de convidados e acompanha as confirmações num painel, sem planilha e sem perguntar para ninguém. O cerimonialista usa o Kore de graça para cuidar de todos os casamentos dos clientes num só lugar.

### Como trabalhamos

- 🇧🇷 Produto em português, código em inglês.
- 🔒 Privacidade desde o início: os dados dos convidados pertencem ao casal (LGPD).
- ♿ Interface acessível (WCAG AA) e pensada primeiro para o celular.
- ✅ Todo merge passa por pull request com CI verde.
